# Release checklist

Nothing is published without the owner's explicit approval. Items marked (owner) need the
developer's machine, accounts or decisions.

## Build and identity
- [x] Package id set: `com.circuitgarden.puzzle` (placeholder) — (owner) confirm final id; it is permanent after first upload
- [x] Portrait only, immersive mode, minSdk 24, targetSdk 36 (Godot 4.7.2 template)
- [x] Launcher icon + adaptive icon layers (`assets/icons/`, generated by `tools/make_icons.gd`)
- [x] Boot splash image and background colour (Android 12+ system splash uses the icon + colour)
- [x] Versioning: `version/code` 1, `version/name` 0.1.0 in `export_presets.cfg`; bump code every upload
- [x] No Android permissions requested (verified in the debug APK manifest)
- [ ] (owner) Install full Android SDK + Gradle build template on Windows
- [ ] (owner) Create upload keystore outside the repo, back it up, set the three `GODOT_ANDROID_KEYSTORE_RELEASE_*` env vars
- [ ] (owner) `build_android.ps1 -Mode release` produces the AAB
- [ ] Device test on at least one phone: `device_test.sh`, then a manual pass (tutorial, 5 levels, garden, store, pause/resume, back button)

## Monetization (before enabling anything live)
- [ ] (owner) Approve enabling ads/purchases
- [ ] Integrate AdMob plugin with **test** ad units; UMP consent flow for EEA/UK
- [ ] Integrate Play Billing plugin; license testers in Play Console
- [ ] Server-side purchase verification for permanent entitlements (see monetization.md)

## Play Console (owner: account creation costs a one-time fee, needs approval)
- [ ] Create app, store listing (`release/store-listing.md`)
- [ ] Upload screenshots (`release/screenshots/`, 1080x1920)
- [ ] Feature graphic 1024x500 (not made yet)
- [ ] Privacy policy hosted at a public URL (`release/privacy-policy-draft.md`) and set in `scripts/main.gd`
- [ ] Support email set in `scripts/main.gd`
- [ ] Data safety form (`release/data-safety.md`)
- [ ] Ads declaration: "contains ads" once AdMob is enabled; "no" while it is not
- [ ] Content rating questionnaire (`release/content-rating.md`)
- [ ] Target audience: 13+ recommended unless we commit to Families policy requirements
- [ ] Internal testing track first, then closed testing (new personal accounts must run a closed test with testers before production)
